Forecasts Bitcoin's US-dollar price 4 hours after each checkpoint from the last 72 hours of 1-minute closes. The model pulls the checkpoint close 5% of the way toward the average of the trailing 4-hour and 8-hour means: trend extrapolation lost to persistence on 26 out-of-sample checkpoints, while this tiny shrinkage beat persistence slightly on every window tested.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
